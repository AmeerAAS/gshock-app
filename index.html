Red Hat OpenShift Deployment Artifacts

Below are all the standard production configuration files needed to deploy this web application on Red Hat OpenShift using standard Nginx container image or OpenShift Source-to-Image (S2I).

Containerfile / Dockerfile (Root level) 
# Use official unprivileged Nginx image for OpenShift security compliance
FROM nginxinc/nginx-unprivileged:alpine

# Copy web app assets to Nginx html directory
COPY index.html /usr/share/nginx/html/index.html
COPY nginx.conf /etc/nginx/conf.d/default.conf

# Expose non-root HTTP port (8080) required by OpenShift SCC
EXPOSE 8080

CMD ["nginx", "-g", "daemon off;"]
nginx.conf 
server {
    listen 8080;
    server_name localhost;

    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    # Enable Gzip Compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;

    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
k8s/deployment.yaml 
apiVersion: apps/v1
kind: Deployment
metadata:
  name: gshock-hybrid-watch
  labels:
    app: gshock-hybrid-watch
spec:
  replicas: 2
  selector:
    matchLabels:
      app: gshock-hybrid-watch
  template:
    metadata:
      labels:
        app: gshock-hybrid-watch
    spec:
      containers:
      - name: watch-app
        image: image-registry.openshift-image-registry.svc:5000/my-namespace/gshock-hybrid-watch:latest
        ports:
        - containerPort: 8080
          protocol: TCP
        resources:
          limits:
            cpu: 200m
            memory: 256Mi
          requests:
            cpu: 50m
            memory: 64Mi
        securityContext:
          allowPrivilegeEscalation: false
          readOnlyRootFilesystem: false
          runAsNonRoot: true
k8s/service.yaml 
apiVersion: v1
kind: Service
metadata:
  name: gshock-hybrid-service
  labels:
    app: gshock-hybrid-watch
spec:
  ports:
  - port: 8080
    targetPort: 8080
    name: http
    protocol: TCP
  selector:
    app: gshock-hybrid-watch
  type: ClusterIP
k8s/route.yaml (OpenShift Route) 
apiVersion: route.openshift.io/v1
kind: Route
metadata:
  name: gshock-hybrid-route
  labels:
    app: gshock-hybrid-watch
spec:
  to:
    kind: Service
    name: gshock-hybrid-service
  port:
    targetPort: 8080
  tls:
    termination: edge
    insecureEdgeTerminationPolicy: Redirect
OpenShift Deployment Commands (`oc` CLI) 
# 1. Login to OpenShift Cluster
oc login --token= --server=https://api.your-openshift-cluster.com:6443

# 2. Create or select project namespace
oc new-project gshock-watch-app || oc project gshock-watch-app

# 3. OPTION A: Quick Deployment directly from GitHub (S2I / Docker build)
oc new-app https://github.com//gshock-watch-app.git \
  --name=gshock-hybrid-watch \
  --strategy=docker

# Expose public HTTPS route
oc create route edge --service=gshock-hybrid-watch

# 4. OPTION B: Manual Manifest Apply
oc apply -f k8s/deployment.yaml
oc apply -f k8s/service.yaml
oc apply -f k8s/route.yaml

# Check app status
oc get pods -w
oc get route gshock-hybrid-route
